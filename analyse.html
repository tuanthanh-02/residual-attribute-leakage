What the editors write

Releases built from it

The de-identifier removes the names; the editors then act on the residual cues. The last release writes the opposite-sex form exactly where the mask writes a placeholder. Every arm leaves the shared keep-list alone — patient and the court have no truthful broader term — and the non-person rule arm additionally keeps a cue that names an institution rather than a person, which is why clinic survives there.

Where SACC is. These are global arms: they edit every lexicon match, whoever it describes. SACC's first principle is closure, which needs a binder reading a dependency parse to decide whom each cue describes, and that cannot run in a browser. The non-person rule is the one scope rule that needs no parse, so it is the closest arm here. SACC's own releases, and what closure contributes, are on the results page.

What the adversary reads

Ask the adversary

The question, the single-token request and the renormalisation are the scorer's own. Nothing is sent until you press Run, and the request count is shown first.

  1. Prior — the same question with no text, asked under both candidate orders, giving π, the adversary's answer before it reads anything.
  2. Posterior — the question again with the release in front of it, giving p.
  3. Read the first token and keep the mass on the option letters, renormalised over them. How that token is asked for depends on the model: the frozen payload, one token at temperature 0 with the top 20 log-probabilities.
  4. Score — d = clip((p − π) / (1 − π), 0, 1), averaged over the orders. The band is δ = .05: above π+δ is Leak, below π−δ is Misled, between them Anon.
  5. Eligibility — if π is already past the register's threshold τ, the entry is dropped: the text cannot add what the adversary assumes without it.

Model and cost

Before you use a key. It stays in this page, in memory, and is sent only to the model provider; the page writes nothing to storage. A key typed into any web page is readable by that page, so use a restricted key and revoke it afterwards. Your text is sent to the provider, so do not paste real personal or patient data. De-identification here stands in for the tagger the released pipeline uses, and the occupation candidates are a demo set rather than the annotation strata.
