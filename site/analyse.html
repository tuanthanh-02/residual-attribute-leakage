What the adversary reads

How it works

How the score is computed, step by step
  1. Ask with no text. Just the question and the answer options. What comes back is π, the prior: how well the model guesses knowing nothing. For a two-way question that should land near .50 — if it is already near 1, the model is guessing from the question, not from your sentence.
  2. Ask again with the text. The same question, this time with one version in front of it. What comes back is p, the model's confidence in the true value after reading.
  3. Read only the first letter. The model answers with a single letter, and the probability it assigned to each option letter is what gets recorded — not the words it would have written. one token at temperature 0, with the top 20 log-probabilities.
  4. Score the gap. L = clip((p − π) / (1 − π), 0, 1) — how much of the room between the prior and certainty the text closed. 0 means the text added nothing, 1 means it gave the answer away. Within ±.05 of the prior the release counts as Anon; clearly above is Leak, clearly below is Misled — the model was pushed towards the wrong value.
  5. Each question is asked twice, once with the true value listed first and once second, and the two are averaged. Models favour whichever option they see first, and averaging cancels most of it.
  6. Drop the entry if there is nothing to measure. If the model already guesses the answer without any text, the text cannot be blamed for it, and the paper leaves such cases out rather than crediting them.
